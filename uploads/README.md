# uploads — مرفوعات المنصة والنوادي

يُنشأ هذا الهيكل تلقائياً عند تشغيل السيرفر (`ensureUploadDirectoryTree`).

| المسار النسبي | الاستخدام |
|----------------|------------|
| `platform/homepage/` | بنر ومعرض الصفحة الرئيسية (من لوحة إعدادات المنصة) |
| `platform/assets/` | أصول المنصة (اختياري) |
| `platform/files/` | ملفات عامة للمنصة (اختياري) |
| `clubs/<id>/logo/`, `banner/`, `courts/`, `offers/` | صور النادي من لوحة التحكم |
| `system/temp/` | مؤقت |

**متغير بيئة:** `PLAYTIX_UPLOADS_DIR` — مسار مطلق لتخزين المرفوعات خارج المستودع (مثلاً على الاستضافة).

**العرض في المتصفح:** الملفات تحت `clubs/...` و`platform/...` تُعرض عبر  
`GET /api/gallery/serve?path=<مسار-نسبي>`  
(مثال: `path=platform%2Fhomepage%2Fbanner.jpg`).

المجلد `Gallery/` في جذر المشروع ما زال يُدعم **للقراءة** للبيانات القديمة حتى تُنقل يدوياً إلى `uploads/` إن لزم.
